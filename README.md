# Bhakti Bazaar (भक्ति बाज़ार)

> **"हर भक्त की भक्ति का हर सामान, एक ही स्थान पर।"**  
> *A premium, authentic Indian devotional e-commerce marketplace and ecosystem for Hindu worship, spiritual literature, sacred idols, and temple crafts.*

---

## 🌟 Overview

**Bhakti Bazaar** is an all-in-one devotional shopping platform connecting devotees with authentic temple artisans and sacred centers across India, including Sri Vrindavan Dham, Mathura, Sri Mayapur, Kashi (Varanasi), and Moradabad. 

It provides an end-to-end e-commerce experience catering to multiple devotional traditions, featuring authentic sourcing guarantees, comprehensive product detail views, real-time multi-stage order tracking, artisan seller management, and administrative governance.

- **Mata Rani (Shakti)**: Banarasi zari chunris, 16-Shringar puja pitari, Durga idols, and Navratri havan kits.
- **Ecumenical / Sanatana Traditions**: Heavy Moradabad brass puja thalis, incense, camphor burners, home mandirs, and car dashboard idols.

## ✨ Key Features & Architecture

### 1. Storefront & Sacred Catalog
- **Bilingual Interface**: Seamless instant toggle between English and Hindi (`हिन्दी / English`).
- **Interactive Filtering**: Filter by sacred category, deity tradition, festival collections (Janmashtami, Radhashtami, Diwali, Navratri, Ram Navami), and special tags (Bestsellers, Braj Direct, Starter Kits).
- **Search & Suggestions**: Real-time autocomplete suggestions covering deities, materials, categories, and Dham origins.
- **Pincode Delivery Estimator**: Realistic delivery estimates, origin hubs, and Cash on Delivery availability across major Indian pincodes.

### 2. Product Detail Page (PDP)
- Multi-angle product imagery with zoom and Zero-Broken-Image fallback containers.
- Sanctity & provenance guarantee certificates for authentic temple sourcing.
- Dynamic size, dimension, and craft variation selectors with real-time price calculation.
- Granular technical specifications and verified devotee customer reviews with review submission.
- Companion & related item recommendations.

### 3. Shopping Cart, Wishlist & Secure Checkout
- Slide-over drawers for **Sacred Basket** and **Wishlist**.
- Multiple saved address management.
- Transparent payment methods:
  - **Cash on Delivery (COD)** with threshold verification.
  - **UPI Transfers** with VPA format validation and 12-digit UTR reference entry.
  - **Debit / Credit Cards** with explicit sandbox authentication.
- Festival coupon engine (e.g., `RADHE10`, `BHAKTI15`).

### 4. Advanced Order Tracking (Vertical Timeline)
- Detailed multi-stage tracking events:
  - `Order Placed`
  - `Sanctified & Packed`
  - `Dispatched from Dham`
  - `Arrived at Hub`
  - `Out for Delivery`
  - `Delivered`
- Dual visualization: an overall progress bar plus an interactive vertical timeline progress bar displaying dates, timestamps, facility locations, and sortation hub codes (`VRN-01`, `MTJ-HUB`, `PNQ-W04`, etc.).

### 5. Seller Studio & Artisan Hub
- Vendor onboarding and registration form.
- Real-time catalog and product creation with image upload and custom attributes.
- Inline pricing (₹) and stock quantity adjustment.
- Order fulfillment queue with status transitions dynamically updating customer tracking.
- Bank settlement and earnings ledger with platform fee breakdown.

### 6. Admin Governance Console
- Revenue share analytics across devotional traditions.
- Catalog governance and SKU management.
- Vendor KYC and Verified Temple Artisan badge approval/revocation.
- Payment reconciliation (e.g., verifying UPI UTR transactions).
- Campaign coupon creator and homepage banner customizer.

## 🎨 Design System

Built under the **Universal Frontend Design Constitution** with an authentic Indian devotional aesthetic:
- **Palette**:
  - *Dominant Canvas*: Warm sacred paper (`#FAF7F2`)
  - *Primary Tone*: Deep temple maroon (`#5B1818`, `#421010`)
  - *Accent*: Sacred saffron & terracotta (`#C85A17`, `#9A3412`)
  - *Highlights*: Temple gold & brass (`#F6C453`, `#D97706`)
  - *Success / Provenance*: Forest emerald (`#1F6E43`)
- **Typography**:
  - Display: `Cormorant Garamond` (editorial serif with devotional grandeur)
  - Body: `Plus Jakarta Sans` (clean, accessible legibility)
  - Data / Currency: `JetBrains Mono` (`font-mono-num tabular-nums`)
- **Anti-Slop Restraint**: Zero meaningless pill capsules, unboxed metadata with typographic separators (`·`), single-line controls, and high-fidelity contextual imagery.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone or navigate to the repository:
   ```bash
   cd /path/to/bhakti-bazaar
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Run linting & type checks:
   ```bash
   npm run lint
   ```
